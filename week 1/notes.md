# Week 1: C

## Key Concepts Learned

*   **Source Code vs. Machine Code:** The difference between the code we write (source code) and the binary instructions the computer understands (machine code).
*   **Compiling:** The process of translating source code into machine code using a compiler (like `clang` or `make`).
*   **Data Types:** Understanding how to store different kinds of data:
    *   `int`: Integers (whole numbers).
    *   `char`: Single characters.
    *   `float`: Floating-point numbers (decimals).
    *   `string`: Text (arrays of characters).
    *   `bool`: Boolean values (true or false).
*   **Control Flow:** Directing how the program runs using:
    *   Conditionals (`if`, `else if`, `else`, `switch`).
    *   Loops (`while`, `for`, `do-while`).
*   **Functions and Abstraction:** Writing custom functions to simplify code, avoid repetition, and make programs easier to read.
*   **Command-Line Interface (CLI):** Navigating the terminal using basic Linux commands (`cd`, `ls`, `mkdir`, `rm`).

## Problem Sets Completed

*   **Hello:** A simple program that prompts the user for their name and prints a greeting.
*   **Mario (More):** A program that takes the height of a pyramid and prints a double half-pyramid with a gap of two spaces in the middle.
*   **Credit:** A program that prompts the user for a credit card number and uses mathematical logic (Luhn's Algorithm) to determine if it is a valid card number and which brand it is (Mastercard, American Express, or Visa).
