# Week 0: Scratch and Computational Thinking 

##  Key Concepts Learned 

* **Algorithms:** Step-by-step instructions for solving a problem. 
* **Binary:** How computers represent data using only 0s and 1s. 
* **ASCII & Unicode:** Systems used to map numbers to letters and characters. 
* **Pseudocode:** Writing out the logic of an algorithm in plain English before coding it. 
* **Computational Thinking:** Breaking down a complex problem into smaller, manageable parts. 

##  Scratch Concepts 

During this week, I learned the fundamental building blocks of programming using Scratch: 

* **Functions (Blocks):** Actions that a sprite can perform. 
* **Loops:** Repeating a set of instructions (`repeat`, `forever`). 
* **Conditionals:** Making decisions based on certain conditions (`if`, `if/else`). 
* **Variables:** Storing data that can change during the program.
